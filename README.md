# Commercial-Scale Open-Source Hybrid Food Dehydrator (50 kg+)

## Project Overview
This repository contains the complete open-source hardware documentation, bills of materials (BOM), and power system architectures for a commercial-scale (50 kg+ capacity) hybrid agricultural food dehydrator. Designed specifically for rural agribusinesses, Farmer Producer Organizations (FPOs), and village-level micro-processing units, this system combines high efficiency, thermal safety, and local manufacturability.

## Key Features
* **Self-Regulating PTC Heating:** Utilizes fan-integrated Positive Temperature Coefficient (PTC) ceramic air heaters that prevent thermal runaway and optimize energy draw.
* **PUF Panel Insulation:** Replaces standard wood with Polyurethane Foam sandwich panels to maximize heat retention and lower operational costs.
* **Hybrid Power Architecture:** Engineered to run smoothly on a direct **12V DC battery bank** or a **Solar-Grid Hybrid setup**, ensuring uninterrupted processing even during rural power outages or low-sun days.
* **Stainless Steel Rolling Trolley:** Designed for heavy-duty batch loading and unloading.
